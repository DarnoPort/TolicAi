# Tolic AI

Экспериментальный аддон для Garry's Mod: NPC с настоящим нейросетевым модулем принятия решений.

> **Текущий статус:** начальная разработка. Этот репозиторий пока не содержит законченного игрового ИИ. Первый рабочий прототип должен проверить связку Garry's Mod → локальный AI-сервис → нейросетевая модель.

## Границы разработки

Проект разделён на два крупных блока. Текущая работа касается только **Блока I — основы NPC**. Блок II (команды игрока) не входит в текущий план реализации и не будет разрабатываться до отдельного разрешения автора.

Основа включает:
- существование одного уникального NPC;
- восприятие игрового мира и получение актуального состояния;
- выбор намерений настоящей нейросетью, а не только набором `if/else`;
- исполнение решений игровым кодом;
- самосохранение, страх боли и смерти;
- отношение к игроку как к наставнику, командиру и существу, которое может возвращаться после смерти;
- адаптацию к мирной и боевой обстановке;
- долговременное обучение и память, переживающую возрождение, без памяти о собственной смерти.

## Архитектурный принцип

Нейросеть выбирает высокоуровневое намерение на основе структурированного наблюдения. Lua-код Garry's Mod отвечает за безопасное исполнение доступных действий, навигацию, физику, игровые события и проверку результата. Это разделение не должно превращаться в скрытую замену нейросети жёсткой системой правил.

## Технологии прототипа

- Garry's Mod Lua: игровая сущность, сбор состояния и выполнение действий.
- Python 3 (стандартная библиотека): небольшой локальный мост между игрой и моделью.
- Ollama API: первый адаптер для вызова локальной нейросетевой модели. Провайдер изолируется от логики NPC, чтобы его можно было заменить после испытаний производительности и качества.

Мост по умолчанию слушает только `127.0.0.1`. Не открывайте его в интернет. В многопользовательской игре сервис должен работать на машине сервера.

## Состояние и запуск
