# Журнал архитектурных решений

## ADR-001 — Игровая логика и инференс разделены

**Статус:** принято для начального прототипа.

Вызов нейросети выполняется отдельным локальным Python-сервисом. Lua-код получает структурированный результат и отвечает за действительность данных и исполнение действий. Это не позволяет медленной генерации напрямую останавливать игровой поток и не требует запускать языковую модель внутри Lua.

Первый адаптер — локальный Ollama API с JSON Schema в параметре `format`. Это отправная точка для испытаний, а не окончательное решение по модели. Выбор подтвердится только после измерения задержки, качества решений и потребления ресурсов.

- Facepunch Wiki, Scripted Entities / NextBot: https://wiki.facepunch.com/gmod/Scripted_Entities
- Ollama API, чат и структурированные ответы: https://github.com/ollama/ollama/blob/main/docs/api.md

## ADR-002 — Долговременный опыт не равен воспоминанию о смерти

**Статус:** принято как требование, реализация впереди.

Краткосрочная история текущей жизни сбрасывается. Долговременный профиль усвоенных привычек и обобщений сохраняется. Событие собственной смерти не записывается в профиль, который будет передан следующей жизни NPC.

Это требование должно быть соблюдено архитектурой памяти с первого дня, а не достигаться только просьбой модели «забыть».

## ADR-003 — Команды игрока исключены из Блока I

**Статус:** принято по требованию автора.

Никакая система интерпретации команд, парсер приказов, окно приказов или отдельный интерфейс управления не входит в первый блок. Взаимодействие с игроком в основе означает наблюдение за ним, обучение на его стиле и обычное следование за ним в рамках автономного поведения, но не разработку системы команд.
